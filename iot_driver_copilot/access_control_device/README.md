# Access Control TCP-to-HTTP Driver (Java)

本驱动通过 TCP 监听门禁设备连接，解析其 HEX 编码报文（固定消息头 + 变长数据 + CRC 校验），并将已解析事件与设备状态以 HTTP 接口提供。驱动不会暴露或转发设备的原生 TCP 协议，而是主动采集并转换为 HTTP。

## 构建与运行

需要 JDK 8+。

编译：

- javac *.java

运行：

- 按下文设置环境变量后：
- java Driver

程序启动后将：
- 启动一个 TCP 服务器等待设备主动连接并持续读取解析
- 启动一个 HTTP 服务器提供查询接口

## 配置（全部通过环境变量）

必须设置以下环境变量（无默认值）：

- HTTP_HOST：HTTP 服务监听地址（例如 0.0.0.0）
- HTTP_PORT：HTTP 服务端口（例如 8080）
- TCP_HOST：TCP 监听地址（例如 0.0.0.0）
- TCP_PORT：TCP 监听端口（例如 9000）
- READ_TIMEOUT_MS：每个设备连接的读取超时（毫秒），用于心跳间隔与超时检测
- INITIAL_BACKOFF_MS：接受或监听失败后的初始重试回退时间（毫秒）
- MAX_BACKOFF_MS：接受失败重试的最大回退时间（毫秒）
- MAX_EVENTS：事件环形缓冲区大小（用于 /events 查询的保留事件数量）

报文格式（必须与设备一致）：

- HEADER_LEN_BYTES：固定消息头长度（字节数）
- DEVICE_ID_OFFSET_BYTES：设备唯一标识在消息头中的字节偏移
- DEVICE_ID_LENGTH_BYTES：设备唯一标识的字节长度
- MSG_TYPE_OFFSET_BYTES：消息类型在消息头中的字节偏移
- MSG_TYPE_LENGTH_BYTES：消息类型字段长度（字节）
- DATA_LEN_OFFSET_BYTES：数据长度字段在消息头中的字节偏移
- DATA_LEN_LENGTH_BYTES：数据长度字段长度（字节）
- DATA_LEN_ENDIAN：数据长度字段字节序（big|little）
- CRC_LENGTH_BYTES：消息尾 CRC 字节数
- CRC_TAIL_ENDIAN：CRC 尾字段字节序（big|little）。算法为 CRC16-Modbus，CRC 尾通常为小端（低字节在前），请按设备实际设置。
- CRC_ENABLE：是否启用 CRC 校验（true|false）
- HEADER_MAGIC_HEX：消息头起始的固有标识（HEX 字符串，用于流中同步对齐）。例如 AA55 或者 7E。

消息类型映射（用于分类上线/心跳/业务）：

- TYPE_ONLINE_VALUES：逗号分隔的消息类型 HEX 值集合（例如 01,0A），表示上线消息类型码
- TYPE_HEARTBEAT_VALUES：心跳类型码集合（例如 02）
- TYPE_BUSINESS_VALUES：业务数据类型码集合（例如 03,10）

说明：设备所有数据通过 TCP 以 HEX 文本传输（每个字节对应 2 个 HEX 字符）。驱动使用 HEADER_MAGIC_HEX 在流中寻址起始，然后根据消息头的数据长度字段计算完整消息长度，提取数据与 CRC 并验证。

## HTTP APIs（仅实现下述 3 个端点）

- GET /devices
  - 作用：列出所有已识别设备及其当前连接状态与最近活动时间
  - 可选参数：
    - status=online|offline|all
    - since=ISO8601 时间（筛选最后消息时间在此之后的设备）
    - limit=分页大小
    - cursor=分页起始索引（从 0 开始）
  - 示例：
    - curl "http://127.0.0.1:8080/devices?status=online&limit=50"

- GET /devices/{deviceId}/status
  - 作用：查询单设备详细运行状态（在线、最近心跳时间、心跳间隔、最近消息时间等）
  - 示例：
    - curl "http://127.0.0.1:8080/devices/01020304/status"

- GET /events
  - 作用：按时间顺序拉取事件（上线、心跳、业务数据）
  - 可选参数：
    - type=online|heartbeat|business
    - deviceId=<设备ID>
    - since=ISO8601 时间
    - until=ISO8601 时间
    - limit=分页大小
    - cursor=游标（事件 ID，从上次返回事件最后一个 ID 开始）
    - order=asc|desc（默认 asc）
  - 示例：
    - curl "http://127.0.0.1:8080/events?type=business&deviceId=01020304&limit=100"

返回 JSON 中 parsedData.rawDataHex 字段是业务数据区的原始 HEX（已按消息头长度和数据长度抽取），messageTypeHex 是消息类型字段的原始 HEX。crcValid 表示 CRC 校验结果。

## 运行日志

驱动会记录：设备连接/断开、接受失败重试、读取超时、解析错误、最新消息时间等关键事件。

## 关闭与安全

支持优雅关闭：CTRL+C 或进程结束会停止 TCP 与 HTTP 服务并清理后台线程。后台采集线程在读取上实现超时，驱动在监听或接收异常时进行指数回退重试。
